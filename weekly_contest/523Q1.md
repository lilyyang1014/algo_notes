### 一刷 (10/10/2026) ❌ 思路正确，但用目标值 n 控制 term 数量

独立想到用 List 生成 Fibonacci sequence，每生成一个 term，就检查最近三个 terms 的和。

```java
list.add(0);
list.add(1);

for (int i = 2; i < n; i++) { // ❌① n 是目标数值，不是 term 数量
    int cur = list.get(i - 1) + list.get(i - 2);
    list.add(cur);

    int sum = list.get(i) + list.get(i - 1) + list.get(i - 2);
    // ❌② 持续生成可能造成 int overflow
    if (sum == n) return true;
}
```

**根因**：混淆了 term 的 index 与目标数值。n=2 时 loop 不执行，漏掉 `0+1+1=2`；目标无法匹配时，又可能继续生成过大的 Fibonacci terms。

讲解后改为按三项之和停止，并使用 long，最终提交 AC。本轮为辅助完成。

> **自检信号**：确定 loop boundary 前，先区分“生成多少项”和“生成到什么数值”；检查最小合法答案 n=2。

**自测点**：为什么三项之和第一次大于 n 时，就可以直接返回 false？

### 题意

判断 n 能否表示为 Fibonacci sequence 中三个 consecutive terms 的和。

```text
Fibonacci sequence：0,1,1,2,3,5,8,13,...

n = 16 → true：3+5+8=16
n = 8  → false：1+2+5=8，但这三项不连续
```

这里 consecutive 指 sequence 中相邻的三个 terms，不是三个连续整数。

### 核心思路（一句话）

**依次生成 Fibonacci terms，检查最近三项之和；等于 n 返回 true，大于 n 返回 false。**

### 正确写法：保留 List 版本

```java
class Solution {
    public boolean threeFibonacciSum(int n) {
        if (n < 2) return false;

        List<Long> list = new ArrayList<>();
        list.add(0L);
        list.add(1L);

        for (int i = 2; ; i++) {
            long cur = list.get(i - 1) + list.get(i - 2);
            list.add(cur);

            long sum = list.get(i)
                     + list.get(i - 1)
                     + list.get(i - 2);

            if (sum == n) return true;
            if (sum > n) return false;
        }
    }
}
```

List 保留加入顺序，因此最后三个 positions 对应 consecutive Fibonacci terms。有序不等于自动 sorting。

### 为什么可以提前停止

连续三项之和依次为：

```text
0+1+1 = 2
1+1+2 = 4
1+2+3 = 6
2+3+5 = 10
3+5+8 = 16
```

三项之和持续增大。一旦超过 n，后面的和只会更大，不需要继续生成。

### 为什么用 long

即使 n 是 int，下一个生成的 term 或三项之和也可能超过 int 范围。使用 long，避免比较之前就发生 overflow。

```java
List<Long> list = new ArrayList<>();
list.add(0L);
list.add(1L);
```

### 复杂度分析

**Time: O(log n)**：Fibonacci terms 按指数速度增长，到三项之和达到或超过 n，只需生成 O(log n) 项。

**Extra space: O(log n)**：List 保存生成的所有 terms。

只保存最近两项也能完成生成，可将 extra space 降为 O(1)；本轮使用 List 版本。

### 沉淀

- **目标值不等于 term 数量。** Loop 应根据三项之和停止。
- **先检查最小合法答案。** 本题第一组就是 `0,1,1`，和为 2。
- **数值增长快时，检查 overflow。** 不只看 input 是否能放进 int，还要看中间计算。
- **Consecutive terms 指相邻 positions。** 不能从 sequence 中任意挑三个数。

### Interview pitch

> "I generate Fibonacci terms in order and check the sum of the latest three terms. If the sum equals n, I return true. If it exceeds n, I return false because the sums keep increasing. I use long to avoid integer overflow."
