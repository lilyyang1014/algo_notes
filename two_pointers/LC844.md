### 核心思路

**从右往左扫描，先遇到 `#`，再遇到它要删除的字符。用 skip counter 找到两边下一个有效字符，直接比较，无须重建 String。**

### 代码

```java
class Solution {
    public boolean backspaceCompare(String s, String t) {
        int i = s.length() - 1, j = t.length() - 1;
        int countS = 0, countT = 0;

        while (i >= 0 || j >= 0) {
            while (i >= 0) {
                if (s.charAt(i) == '#') {
                    countS++;
                    i--;
                } else if (countS > 0) {
                    countS--;
                    i--;
                } else {
                    break; // 保留有效字符，交给外层比较
                }
            }

            while (j >= 0) {
                if (t.charAt(j) == '#') {
                    countT++;
                    j--;
                } else if (countT > 0) {
                    countT--;
                    j--;
                } else {
                    break;
                }
            }

            if (i >= 0 && j >= 0) {
                if (s.charAt(i) != t.charAt(j)) return false;
            } else if (i >= 0 || j >= 0) {
                return false; // 只有一边还有有效字符
            }

            i--;
            j--;
        }

        return true;
    }
}
```

内层结束后，pointer 要么停在有效字符上，要么已小于 0。外层统一处理：

- 两边都有字符：比较。
- 只有一边有字符：返回 false。
- 两边都没有字符：比较完成。

多余的 `#` 不需要额外处理：pointer 扫到负数后，即使 counter 仍大于 0，也已经没有字符可删。

### 复杂度分析

**Time: O(n+m)**：两个 pointer 只向左移动，每个字符只处理常数次。
**Space: O(1)**：只维护两个 pointer 和两个 counter。

### Brute force：正序重建后比较

用 StringBuilder 模拟 stack：普通字符追加到末尾，遇到 `#` 就删除末位；为空时忽略。

```java
class Solution {
    public boolean backspaceCompare(String s, String t) {
        return getString(s).equals(getString(t));
    }

    private String getString(String str) {
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < str.length(); i++) {
            if (str.charAt(i) != '#') {
                sb.append(str.charAt(i));
            } else if (sb.length() > 0) {
                sb.deleteCharAt(sb.length() - 1);
            }
        }

        return sb.toString();
    }
}
```

**Time: O(n+m)，Space: O(n+m)。** 倒序版保持同阶时间，并省去重建结果的空间。

API 提醒：

- String 内容比较用 `equals`，不用 `==`。
- String / StringBuilder 用 `length()`，array 用 `length`。
- StringBuilder 的 `deleteCharAt` 删除末位为 O(1)，删除中间位置需要移动后续字符。
- 只读一个字符用 `charAt`，无须转 array；StringBuilder 若需转 array，可用 `sb.toString().toCharArray()`。

### 沉淀

- **counter 数的是待删除的普通字符，不是 pointer 要移动的格数。** 遇 `#` 累加，遇需要删除的普通字符才减一。
- **定位与比较后的推进分开。** 内层找到有效字符就停，外层比较后才跳过它。
- **scope 合法与 index 合法是两回事。** variable 在外面能用，不代表它的值能直接用于 `charAt`。
- **复合 condition 的 else 可能包含多种情况。** 「不是两边都有」还要区分单边耗尽和两边都耗尽。
- **选择能减少切换判断的结构。** 本题两种字符会交替出现，每轮重新分类，比维护两个处理阶段更直接。

### 引申：从重建到直接比较

正序处理需要保存已经留下的字符；倒序处理可以先累计待删除数量。进一步看，题目只要求判断相等，不要求输出结果，因此找到有效字符后直接比较即可。

**操作只影响一侧时，尝试从另一侧处理；只需要比较结果时，检查是否真的需要存下结果。**
