**②的根因**：append 表示已经用掉一个面额，num 必须同步扣减；只改输出、不改剩余值，loop 就无法结束。

### 核心思路（一句话）

**按降序尝试 13 个合法面额；剩余值够用就追加对应 symbol，并扣掉面额，直到当前面额不能再用。**

### 正确写法

```java
class Solution {
    public String intToRoman(int num) {
        int[] values = {
            1000, 900, 500, 400, 100, 90, 50,
            40, 10, 9, 5, 4, 1
        };
        String[] symbols = {
            "M", "CM", "D", "CD", "C", "XC", "L",
            "XL", "X", "IX", "V", "IV", "I"
        };

        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < values.length; i++) {
            // 外层换面额；内层重复使用当前面额
            while (num >= values[i]) {
                sb.append(symbols[i]);
                num -= values[i]; // 追加与扣减必须同步
            }
        }
        return sb.toString();
    }
}
```

### 为什么 greedy 成立

本题按 thousands、hundreds、tens、ones 分别编码。每个 decimal place 的规则固定：9 用减法形式，5～8 先用五倍单位，4 用减法形式，1～3 重复单位 symbol。

降序表把这些规则直接编码进了面额和顺序，因此逐个取用会生成标准罗马数字。**不是任意面额表都能 greedy**：`{1,3,4}` 凑 6，取最大得到 `4+1+1`，却不如 `3+3`。

### 复杂度分析

**Time: O(1)**：`num ≤ 3999`，固定 13 个面额，每个面额最多使用 3 次。
**Space: O(1)**：两张固定表，输出长度也有固定上限。

### 沉淀

- **condition 先说成人话**：「剩余值够不够当前面额」→ `num >= values[i]`，不要凭大小关系的外形写。
- **输出与剩余状态同步 update**：每 append 一个 symbol，就扣掉对应 value；否则结果变了，loop 的状态却没变。
- **分清换面额与重复使用**：外层 for 换面额，内层 while 用尽当前面额；if 不能表达重复次数。
- **修完要重新 dry run**：补一行不等于整段已正确，尤其检查 condition 和 update 是否配合。
- **容器必须支持算法需要的顺序**：本题用两个数组通过同一个 index 对齐；HashMap 不保证按面额降序遍历。

### 引申：什么时候用 StringBuilder

循环中反复构建字符串，优先用 StringBuilder。反复 `s += piece` 通常需要不断复制已有内容；若追加总长度为 n，累计成本可能达到 O(n²)。

StringBuilder 追加单个字符通常为摊还 O(1)，追加长度为 k 的字符串需要 O(k)；最后调用一次 `toString()` 得到 String。

| 调用                 | 返回                           |
| -------------------- | ------------------------------ |
| `sb.append(x)`       | StringBuilder 自己，可链式调用 |
| `sb.toString()`      | String                         |
| `sb.reverse()`       | 自己                           |
| `sb.deleteCharAt(i)` | 自己                           |
| `sb.length()`        | int                            |
| `sb.setCharAt(i, c)` | void                           |
