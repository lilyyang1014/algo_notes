### 核心思路（一句话）

**Queue 按 BFS 顺序保存待访问的 nodes；每轮先固定当前层的数量，处理完这批 nodes，再进入下一层。**

### 正确写法

```java
import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.List;
import java.util.Queue;

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();

        if (root == null) return ans;

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            List<Integer> level = new ArrayList<>();
            int size = queue.size();

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);

                if (node.left != null) {
                    queue.offer(node.left);
                }

                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            ans.add(level);
        }

        return ans;
    }
}
```

### 为什么先保存 size

每次进入 while 时，queue 中恰好是当前层的 nodes。处理过程中，poll 移除当前层的 node，offer 加入下一层的 children，动态的 queue size 已不再代表本层原有的数量。

```java
int size = queue.size();
for (int i = 0; i < size; i++) {
    // 只处理进入本轮时已有的 nodes
}
```

例如 queue 中有两个 leaf nodes。若直接写 `i < queue.size()`，处理第一个后，i 变为 1、queue size 也变为 1，loop 提前结束，第二个 node 被错误分到下一层。

### Queue 存什么

```java
Queue<TreeNode> queue = new ArrayDeque<>();
```

存 TreeNode reference，不只存 val，因为出队后还需要读取 left、right。

```java
queue.offer(node);           // 加到队尾
TreeNode cur = queue.poll(); // 从队头取出并返回
```

TreeNode 是类型，root / cur 是 reference variables。root 始终指向最初传入的 root，poll 不会改变它。

先 offer left，再 offer right，保证同一层从左到右输出。

### 与 Graph BFS 的关系

都是通过 queue 逐层扩展。

合法 binary tree 没有 cycle，只沿 child 方向访问时，每个非 root node 只有一个 parent，因此不需要额外的 visited。

若只要求返回分层结果，也可以用 DFS + depth，将 val 放入对应层的 list；实际访问顺序则不是逐层的。

### 复杂度分析

设 n 为 node 数量，w 为最大层宽。

**Time: O(n)**：每个 node 入队、出队各一次。  
**Auxiliary space: O(w)**：queue 和当前层 list 最多占 O(w)，最坏为 O(n)。  
**Output space: O(n)**：ans 保存所有 node values。

### 沉淀

- **取出后使用返回的对象。** Poll 不会改变 root 的指向。
- **遍历与分层分别落实。** While 负责持续处理，固定 size 的 for 负责当前层。
- **Empty tree 在入队前处理。** ArrayDeque 不接受 null。

### 关联

- Graph BFS — 相同的 queue 扩展过程；tree 的结构让邻居获取和重复访问处理更简单。
