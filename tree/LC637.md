### 一刷 (10/13/2026) — BFS 写对，类型转换不熟

```java
int sum = 0; // ❌ 累加可能 overflow
Double avg = (Double) sum / size; // ❌ int 不能直接 cast 成 Double
```

**根因**：混淆了 double 和 Double。已讲解修正，未记录独立 AC。

### 类型判断：先算右边，再赋值

Numeric 运算按 `double > float > long > int` 统一类型；byte / short / char 至少提升为 int。

```java
double a = 7 / 2;          // 先算出 int 3，再变成 3.0
double b = (double) 7 / 2; // 先转 double 再除，得到 3.5
```

**本题直接用 double sum**，取出 node 时累加，不需要额外的 list：

```java
double sum = 0;       // 每层重新初始化
sum += node.val;     // double + int → double，自动转换
ans.add(sum / size); // double / int → double，再自动 boxing 成 Double
```

`double` 用于计算，`Double` 用于 `List<Double>` 这类 generic types。

> **自检信号**：右边是什么类型在运算？要保留小数或防 overflow，就在运算前选好类型。
