# LC117 — Populating Next Right Pointers in Each Node II

## Goal

- Connect each node to the next node on the same level.
- The last node on each level points to `null`.

## Clarify

- Can `root` be `null`? Yes.

## Method 1 — Queue

- Process nodes level by level.
- Connect each node to the next node on the same level.
- tc: O(n)
- sc: O(w), where `w` is the maximum width of the tree.

## Method 2 — Pointers：走当前层 → 连下一层 → 换层

- Use each node's `next` pointer to walk through the current level.
- Connect the children to build the next level.
- Move to the start of the next level and repeat.
- tc: O(n)
- sc: O(1)

### Pointers in Method 2

- `cur`: walks through the current level.
- `dummy`: remembers the start of the next level.
- `tail`: connects the children on the next level.

### Code

```java
class Solution {
    public Node connect(Node root) {
        if (root == null) return root;
        Node cur = root;
        while (cur != null) {
            Node dummy = new Node(0);
            Node tail = dummy;
            while (cur != null) {
                if (cur.left != null) {
                    tail.next = cur.left;
                    tail = tail.next;
                }
                if (cur.right != null) {
                    tail.next = cur.right;
                    tail = tail.next;
                }
                cur = cur.next;
            }
            cur = dummy.next;
        }
        return root;
    }
}
```

## Edge Cases

- Empty tree: `[]`
- Single node: `[1]`
- Left-skewed tree: `[1,2,null,3]`
- Right-skewed tree: `[1,null,2,null,3]`
- Full tree: `[1,2,3,4,5,6,7]`
- Sparse tree: `[1,2,3,4,null,null,7]`

## 口语版本

My goal is to connect each node to the next node on the same level.
I can use a queue to process the tree level by level. That takes O(n) time and O(w) space.
For constant space, I use each node's `next` pointer to walk through the current level. As I go, I connect the children to build the next level. Then I move to the start of that level and repeat.
I use a dummy node to remember the start of the next level, and a tail pointer to connect its nodes. The time is O(n), and the extra space is O(1).
