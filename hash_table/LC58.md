## 58. Length of Last Word

Date: 一刷 9/11/2026
Difficulty: Easy
Tags: string, char, 从后往前扫

### 一刷 (9/11/2026) ❌ `'x'` 写成 `"x"`（compile error）

```java
if (s.charAt(i) == " ") break;   // ❌ charAt 返回 char，" " 是 String，两边类型不同
```

**根因**：`'a'` 是 char（只能放一个字符，本质是整数），`"a"` 是 String（对象）。Java 里 `char` 和 `String` 之间没有 `==` 的重载，编译器当场拦——**这次是便宜的那种**。改成 `' '` 即可。

**同族第三次**：LC13 一刷 `s.charAt(i) == "V"`（六个分支全是）、二刷 `Map<String,Integer>` 配 `charAt`。**三次里只有这次和 13 一刷是编译期拦下的**；13 二刷那次走的是 `containsKey`，参数类型是 `Object` 不是 `K`，编译器不拦 → 恒 false → 累加那行一次都没执行，静默到底。**同一个混淆，落在 `==` 上当场崩，落在 `containsKey` 上能一路错到底。**

### 正确写法

```java
public int lengthOfLastWord(String s) {
    int sum = 0;
    for (int i = s.length() - 1; i >= 0; i--) {
        if (sum > 0 && s.charAt(i) == ' ') break;   // 已进单词又撞空格 → 单词结束
        if (s.charAt(i) != ' ') sum++;              // 尾部空格在 sum==0 时被放过
    }
    return sum;
}
```

**这个 loop 要干两件事**：跳过尾部空格、数最后一个单词。两件事的终止条件相反（一个遇非空格停、一个遇空格停），所以要么拆两层结构，要么给一个状态变量——这里 `sum > 0` 就是那个状态变量，它在回答「我进单词了没有」。

等价的两段式写法（更直白，但多几行）：

```java
int i = s.length() - 1;
while (i >= 0 && s.charAt(i) == ' ') i--;      // 段一：跳尾部空格
int sum = 0;
while (i >= 0 && s.charAt(i) != ' ') { sum++; i--; }   // 段二：数单词
return sum;
```

**为什么从后往前**：题目只要最后一个单词。从前往后得一路数到底还要记住上一个单词的长度，从后往前第一个撞上的就是答案，一遍走完不回头。

### 复杂度分析

**Time: O(n)** 最坏扫全串（整串一个单词时）；**Space: O(1)**。

不要用 `s.trim().split(" ")`：能过，但建了一个新字符串加一个数组，O(n) 额外空间，且面试里会被追问「不用库函数怎么写」。

### 沉淀

- **中括号和 `charAt` 的括号里放的是「第几格」，取出来的才是「那一格的东西」。** 写完指着那个变量问一句：我手上这个是位置还是内容。同族：189 的 `n-k`、367 的 `x` 与 `num`、704 的 `nums[left]` 应为 `left`。
- **一个变量身兼两职时，问一句「这两个答案会不会分叉」。** 这里 `sum` 既是计数器又是「已进单词」的 flag，安全的前提是计数一旦开始就不会退回 0。换个题（比如计数中途可以合法归零），这个 flag 就假了，得拆出独立的 boolean。
- **一个循环被指望干两件终止条件相反的事时，要么加一层结构、要么加一个状态变量。** 同 LC135 四刷（遍历 + 挑位置）、LC12 二刷（换面额 + 连用同一面额）。
